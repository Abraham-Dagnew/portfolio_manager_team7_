# Portfolio Manager

A full-stack portfolio management application built as a training project. It lets a single user track a financial portfolio of stocks, ETFs, bonds, and cash — buying and selling against a real cash balance, and viewing live performance backed by real market data from Yahoo Finance.

## Features

- **Browse holdings** — view every position currently held, with live buy/delete actions and ticker search/filtering.
- **Buy assets** — search for a real stock, ETF, or bond by ticker or company name, auto-fill the live market price, and purchase it. Purchases are validated (ticker format, positive quantity/price, real purchase date) and are rejected if they'd exceed your available cash balance.
- **Cash balance tracking** — a single running cash balance funds every purchase. Deposit or withdraw funds freely (withdrawals can't take the balance below $0), and the balance updates live as you buy, sell, or delete holdings. Deleting a holding refunds its original cost back to the balance.
- **Portfolio performance dashboard** — live total value, total cost, total gain/loss, and % return, computed against real-time prices. Includes a gain/loss chart per holding and an asset allocation chart showing portfolio composition.
- **Live market data** — ticker validation, price lookups, and search are all backed by real Yahoo Finance data via `yfinance`, not mocked/static data.
- **Interactive API docs** — full Swagger/OpenAPI documentation auto-generated by FastAPI.

## How to Use

1. **Browse Holdings** (`/portfolio`) — see everything you currently own. Search by ticker to filter the list, or delete a holding (this refunds its cost to your cash balance).
2. **Buy** (`/add`) — search for an asset by ticker or name, select it from the results, and its type and live price auto-fill. Enter a quantity and submit. The purchase is rejected with a clear message if the ticker isn't valid or if it would exceed your cash balance.
3. **Performance** (`/performance`) — see how your portfolio is doing: summary cards for total value/cost/gain/%, a gain/loss chart, an asset allocation chart, and a detailed table — all using live prices.
4. **Cash Balance** (sidebar, always visible) — see your current balance, and use the `+`/`-` controls to deposit or withdraw funds at any time.

## Technologies Used

**Backend**
- [Python](https://www.python.org/) / [FastAPI](https://fastapi.tiangolo.com/) — REST API framework
- [Pydantic](https://docs.pydantic.dev/) — request validation (tickers, positive numbers, enums, dates)
- [MySQL](https://www.mysql.com/) (`mysql-connector-python`) — persistent storage for holdings and cash balance
- [yfinance](https://pypi.org/project/yfinance/) — live market data (prices, search) from Yahoo Finance
- [Uvicorn](https://www.uvicorn.org/) — ASGI server

**Frontend**
- [Flask](https://flask.palletsprojects.com/) — serves the HTML pages
- Vanilla JavaScript (ES modules) — API calls, form validation, live UI updates, no framework/build step
- [Chart.js](https://www.chartjs.org/) — gain/loss and asset allocation charts
- Hand-written CSS — sidebar/dashboard layout, toast notifications, responsive design

**Testing**
- Python `unittest` — backend endpoint and business-logic tests (`tests/`)
- JavaScript tests for frontend API helpers (`frontend/tests/`)

## Getting Started

### 1. Install dependencies

```powershell
python -m pip install -r requirements.txt
python -m pip install -r frontend\requirements.txt
```

### 2. Configure your database

Copy `.env.example` to `.env` and fill in your local MySQL credentials.

### 3. Create the database tables

```powershell
python db_conn.py
```
This creates the `portfolio` table and seeds a `balance` table with a starting cash balance of $10,000.

### 4. Start the backend

```powershell
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

### 5. Start the frontend (in a second terminal)

```powershell
cd frontend
python app.py
```

Then open `http://127.0.0.1:5000/portfolio` in your browser.

### 6. Explore the API directly

Interactive Swagger docs are available at `http://127.0.0.1:8000/docs`.

## Running Tests

```powershell
python -m unittest discover tests -v
```

## API Reference

| Method | Endpoint | Description |
|---|---|---|
| GET | `/portfolio` | List all holdings |
| POST | `/portfolio` | Buy a new holding (validates ticker, funds, etc.) |
| DELETE | `/portfolio/{id}` | Delete a holding and refund its cost |
| GET | `/portfolio/performance` | Holdings enriched with live prices + portfolio summary |
| GET | `/stocks/search?q=` | Search real tickers/companies (stocks, ETFs, bonds) |
| GET | `/stocks/price/{ticker}` | Look up a ticker's live price |
| GET | `/balance` | Get current cash balance |
| POST | `/balance/deposit` | Add funds to the balance |
| POST | `/balance/withdraw` | Remove funds from the balance (can't go below $0) |
